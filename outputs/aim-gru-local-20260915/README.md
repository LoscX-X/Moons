# 本机 GRU 48 训练结果

已完成 20 轮，每轮训练 407,387 个窗口。最佳验证检查点来自第 20 轮。
模型：单层 GRU(7,48) + Linear(48,2)，8306 个参数，观察窗口 16。

## 耗时与内存

- 设备：CPU，8 线程，batch 512，PyTorch 2.13.0+cpu。
- 本次从第一轮继续训练的进程耗时：244.62 秒。
- 所有完整轮次的训练及一步验证耗时合计：253.34 秒；不含初始化和最终连续回放。
- 本次训练进程峰值工作集：375.0 MiB。
- 本次训练进程峰值提交内存：1159.1 MiB；与实际驻留物理内存不同。
- 上述内存只统计训练 Python 进程，不包括整机其他软件和系统文件缓存。

## 验证集对照

一步评估使用相同的 20,000 个验证窗口。连续回放每个 UUID 一条，共 295 条；表中均为 Yaw / Pitch 平均绝对误差。

| 方法 | 一步误差 | 5 步累计角度误差 | 20 步累计角度误差 |
| --- | ---: | ---: | ---: |
| 保持角度 | 3.9766° / 1.7739° | 14.8744° / 7.0510° | 36.9260° / 10.9329° |
| 重复上一步动作 | 3.0325° / 1.4447° | 18.2005° / 11.1133° | 52.2799° / 38.8291° |
| 历史回归 | 2.7508° / 1.2292° | 14.1517° / 6.5987° | 36.5774° / 10.6370° |
| 历史 + 水平几何回归 | 2.7389° / 1.2302° | 10.6523° / 6.6043° | 16.3358° / 10.6564° |
| 本次 GRU 48 | 2.3070° / 1.0967° | 9.5625° / 6.1425° | 16.2229° / 10.0008° |

## 如何理解

- 对比同批验证窗口的水平几何回归，一步 Yaw/Pitch MAE 分别降低约 15.8% / 10.9%。
- 20 步累计 Yaw MAE 仅从 16.3358° 改善到 16.2229°，Pitch 从 10.6564° 改善到 10.0008°；长序列收益比一步收益小。
- 相同回放窗口上，第一轮检查点的 20 步 Yaw MAE 为 14.8087°，优于本次第 20 轮的 16.2229°。更多轮次的一步误差改善没有同步转化为长期误差改善。
- best.pt 根据一步验证分数选择，并未根据连续回放误差选模型。
- 这些结果描述角度预测误差；没有检验真人动作分布，也不是命中率。
- 连续回放将模型角度反馈给下一步，目标/玩家的水平几何使用外部记录；不是游戏物理仿真。
- 本模型尚无明确的目标 Pitch 输入，未导出 ONNX，未接入客户端。
- 本次没有评估测试集，以免在后续模型比较期间继续使用测试结果选参数。

```powershell
.\build\aim-training-venv\Scripts\python.exe tools\aim_training\train.py train build\aim-gru-data-verified outputs\aim-gru-local-20260915\gru48 --device cpu --threads 8 --epochs 20 --resume
```
