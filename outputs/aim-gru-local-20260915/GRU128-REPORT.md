# 本机 GRU 128 训练与回放比较

已完成 13 轮。单层 GRU(7,128) + Linear(128,2)，52,866 个参数。
与 GRU 48 使用相同的数据、16 步输入、batch 512、学习率 0.001、随机种子和一步训练目标；新增每轮检查点保存。

## 训练资源

- CPU 8 线程，训练及最终默认验证进程耗时 293.10 秒。
- 各轮训练及一步验证耗时合计 287.94 秒；后续逐轮回放另行执行。
- 训练 Python 峰值工作集 414.6 MiB，峰值提交内存 1196.2 MiB。

## 两个模型文件各自代表什么

- [best.pt](gru128/best.pt)：第 8 轮，按原有一步验证标准选出。
- [best-rollout.pt](gru128/best-rollout.pt)：第 7 轮，按 5/20 步回放标准选出。
- 回放选择标准在本次逐轮评估前固定：GRU 相对水平几何回归的 MAE 比值，对 Yaw、Pitch 和 5/20 步等权平均，越小越好。
- 每轮训练目标仍然是一步 SmoothL1；本次改变的是模型容量，并额外比较了检查点选择方式，没有声称已做多步训练。
- 回放优选使用验证集选择，因此其报告值不是未触碰测试集上的泛化成绩。此轮没有评估测试集。

## 使用范围

这些指标描述离线角度预测和使用外部世界几何的连续回放，不是实际游戏控制或拟人程度的证明。目标 Pitch 输入仍缺失，尚未接入客户端。

## 复现

```powershell
.\build\aim-training-venv\Scripts\python.exe tools\aim_training\train.py train build\aim-gru-data-verified outputs\aim-gru-local-20260915\gru128 --device cpu --threads 8 --hidden 128 --epochs 20 --keep-epochs --resume
.\build\aim-training-venv\Scripts\python.exe tools\aim_training\compare_epochs.py build\aim-gru-data-verified outputs\aim-gru-local-20260915\gru128 --reference outputs\aim-gru-local-20260915\gru48\best.pt --reference-early build\aim-gru-one-epoch\best.pt
```

运行目录已存在时训练需用 --resume；如果已到指定总轮数则不会重新训练。

完整逐轮结果见 [epoch-rollout-comparison.json](gru128/epoch-rollout-comparison.json)。原始每轮检查点保存在本机 gru128 目录，结果 ZIP 仅收录两个优选检查点和最后一轮检查点。
